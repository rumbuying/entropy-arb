# 完整网格记录导出

详情页记录区的「导出完整记录」下载一个 ZIP，替代以前仅下载当前分页的 CSV。无论当前打开订单、成交、配对、档位还是事件，都导出该网格全部历史记录。

包含订单意图、原始订单回执、实际成交、配对分配、资金费、资金变动、全部配置版本和档位、库存批次、操作履历、发单尝试和保护订单绑定。manifest.json 记录网格状态、版本/epoch、快照时间、事件水位，以及每个 CSV 的行数与 SHA-256。未混入其他网格的归属成交和资金费。

所有文件从同一个 SQLite 只读事务生成；快照开始之后的成交、资金费和操作不会混入。导出不调用交易所、不打开凭证库、不修改运行库，也不提交任何交易操作。只反映已经提交的本地记录，不意味着缺失的交易所历史已经完整覆盖。

金额和原生大整数编号直接保留字符串，不转为浮点数。CSV 使用 UTF-8 BOM，公式形式的文本添加前置单引号；在表格软件导入时把金额、地址、订单号和交易号列设为文本，避免表格软件自行四舍五入或科学计数。不要直接以 Excel 的自动识别结果代替原始 CSV 数值。

归档在独立线程逐行写入权限私有的临时文件，下载按固定偏移分块传输，不把整份账本加载到运行时内存或占用控制连接。最多两个生成/下载任务；取消中的工作线程仍占额度，防止反复断开产生无限线程。下载完成释放临时归档，放弃下载由后台有效期清理，服务关闭也清理。响应禁止缓存，查询参数 token 不授予导出权限；有 token 的网站使用 Authorization 请求头。

接口：GET /api/grid/<grid_id>/export。下载中断时完整文件长度不成立，不能把截断 ZIP 伪装为成功。当前浏览器通过 Blob 接收完整文件，因此极大归档仍会占用浏览器内存；服务器端生成和传输内存有界。

专项验证覆盖超过 355 条事件的全量导出、巨大编号及极小 Decimal、其他网格隔离、资金费归属、每个文件哈希、快照后的并发写入排除、重复偏移、失效/限额/取消清理，以及真实 HTTP→RPC 下载鉴权。完整性哈希用于检查文件一致性，不是交易所签名证明。
