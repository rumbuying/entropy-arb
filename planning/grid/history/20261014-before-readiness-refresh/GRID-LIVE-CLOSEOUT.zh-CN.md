## 本轮已完成

- 每次生产网格发送前，以保存的每格数量重新核对实际账户、仓位、已有订单、预算、手续费与已入账资金费。新单也进入最坏敞口与费用计算。恢复和补单不自动改变数量。
- 获取风险快照后检查版本、epoch、资金预留、成交/资金费账本、其他订单、覆盖状态和账户消息代次是否变化；签名后在 HTTP 发送前再检查。风险许可最长5秒，原生行情/账户时间也必须足够新。
- 无待补订单时，每5秒调度一次生产账户风险核对。后台任务并发有界，并与同一账户的发送锁串行，避免把自己的在途订单误判为外来订单。
- 风险失败先推进 epoch、暂停新增，再撤本网格订单；保留实际库存和市场占用。新暂停/停止优先，旧观察结果不覆盖新操作。尚未处理的成交先留待入账，未发送订单保持可核对。
- 持续核对不创建网页预览记录。最新结果持久化在 risk-watch，详情 RPC 可读取；本阶段未修改网页显示。
- 结束平仓使用最新市场报价计算减仓 IOC 的滑点边界。旧 actor 价格不再用于真实平仓。拒单或 UNKNOWN 后不连续重发，缺报价或报价过期使操作明确失败并保留仓位；仍须账本与实际仓位、订单同时清零才释放占用。

这些动作是运行时拦截与撤单，**尚不能代替交易所侧止损**。服务停止或网络断开时的仓位保护、低于最小金额的残仓仍未解决。

## 现在使用者可执行的步骤

1. 打开已启动的持久[网格账户页面](http://127.0.0.1:8789/#/grid/accounts)。如果使用历史页面且提示「临时验收环境」，不要在该页面填写真实密钥。历史 serve_isolated 页面关闭后会删除配置。
2. 在交易所准备与套利分开的资金账户和有名称、可查询有效期的 API 代理钱包。资金地址与签名代理地址是不同字段；私钥只填网格账户表单。
3. 保存账户后点击「检查接入」。检查授权、账户模式、可选合约目录、资金余额、现有订单/仓位、签名准备的结果；失败项需要先处理。账户保存无需选择币种，创建网格时再选；检查不会下单。
4. 接入通过后安排实际执行验收。当前网页还不能执行真实开单；接入通过也不会自动启用交易。完成下表的代码与实际验收后再放行首笔小额网格。
