# 当前实盘版操作说明

入口：[网格账户](http://127.0.0.1:8789/#/grid/accounts)、[创建网格](http://127.0.0.1:8789/#/grid/create)。当前网站只运行在这台电脑；与旧套利网站、配置和执行服务分开。使用者负责使用不同的真实资金账户。

## 创建前

保存账户只登记资金地址、签名凭证和接入信息，不下单，也无需选币种。检查接入核对授权、模式和资金；检查通过后，账户卡列出的已审核市场才允许实盘。当前已保存账户的 BTC、ETH 做多 GTC 全仓已开放，1–3 倍；其他设置仍只读。

## 创建网格

1. 进入创建页，选择账户和 BTC 或 ETH。币种属于这次网格，不属于账户。
2. 设置方向、区间、格数、资金、杠杆、建仓方式和止损。历史验收价格已经过时，按当前行情重新设置。
3. 参数变更后会自动生成最新预览；过期后点击「更新预览」。检查每格数量、预计费用、资金预留、风险说明和实盘资格。多个网格共同使用账户余额；不能给每个币种各分配整份余额。
4. 确认实际参数再创建并启动。参数变化需要重新预览。页面等待或请求仍在进行时查询原请求结果，避免再创建一份。
5. 在详情页确认状态、实际持仓、挂单和保护。服务运行只说明进程存活，网格也可能处于暂停或待核对。

## 管理和结束

- 暂停：撤销普通网格挂单，保留已成交仓位，暂停期间不续单；原生保护仍需查看状态。暂停不等于平仓。
- 恢复：先核对真实订单、成交和库存，再按当前配置重建；不会自动放大每格数量。
- 追加缓冲：增加预算，不增加每格交易规模；账户余额和该网格资格额度仍会检查。
- 调整区间或规模：需要新预览。旧库存保留原退出价格，新订单使用新版本。
- 结束并平仓：先撤普通订单、核对迟到成交，再只减仓退出。只有真实仓位与订单均为零，才显示已结束并释放占用。
- 结束并保留仓位：保留实际敞口及占用，后续仍需处理；不适合把账户彻底清空。

请求显示进行中、待核对或退出失败时，先看操作结果和保留的仓位，不把按钮点击成功当作已经清仓。未知下单结果由程序先查询，不通过反复点击或手工删库处理。

## 收益口径与运行条件

净收益包含已实现收益、浮盈亏、真实交易费和净资金费。累计净收益率的分母为初始投入加累计追加（包括缓冲和规模增加）；减资和结束释放预留不重置分母。有持仓时收益率为估算，历史缺口显示待核对。它是简单累计 ROI，不是时间加权收益率。

关闭浏览器不停止执行服务。当前两个服务会在 macOS 登录后启动并在退出后恢复；电脑睡眠、关机或网络断开时不能保证网格继续补单。交易所已经挂置的原生保护由交易所执行。全天运行的服务器部署仍未完成。

升级、迁移或恢复数据库前按 [服务管理](GRID-SERVICES.zh-CN.md) 和 [在线备份](GRID-BACKUP.zh-CN.md) 处理；不要删除账本或用旧手动进程脚本重启。实盘范围以 [当前状态](LIVE-READINESS.md) 为准。

## 下载运行记录

详情页记录区点击「导出完整记录」，下载该网格全部订单、成交、资金费、配对、配置版本和操作履历的 ZIP，不受当前页影响。解压后 CSV 可用于核对，manifest.json 给出快照时间、行数和文件哈希；快照之后的变化下次重新导出。金额和原生编号列请按文本导入表格软件。详见 [完整导出说明](GRID-EXPORT.zh-CN.md)。

## 可选收益止盈止损

创建页展开「收益止盈止损」，选累计净收益金额或初始投入收益率，止盈填正数、止损填负数，空白表示不设置。收益含实际费用和资金费；达到阈值先停止补单再结束并平仓。保护收益率以创建时初始投入固定计算，追加资金不改变触发线，与详情的累计ROI分母不同。正常暂停时仍监控，数据缺失时显示需处理；依赖本机服务，保留交易所原生价格止损。启动时已发生真实建仓费用也可能立即触发，不把自动保护接管当作未曾成交。详见 [收益保护](GRID-PROFIT-PROTECTION.zh-CN.md)。

开单页闲置不会反复更新预览；后台页面的待计算会在回到前台后继续。旧结果可以查看，但只有未过期的新预览允许确认。详情见 [预览节流与过期说明](GRID-PREVIEW-QUEUE.zh-CN.md)。
